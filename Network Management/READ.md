# 🌐 Network Management

This folder contains **study notes, textbooks, reference books, video courses, standards, RFCs, and practical resources** for the **Network Management** subject.

The resources are useful for **M.Tech NMIS exam preparation**, understanding network management concepts, and developing practical networking skills for cybersecurity.

---

## 📚 Textbooks

- Network Management Fundamentals

Useful for:
- Routers
- Switches
- VLANs
- IP addressing
- Routing
- DHCP
- Network troubleshooting

---

## Wireshark

Network protocol analyzer used to capture and inspect network traffic.

Useful for:
- Packet analysis
- TCP/IP analysis
- Protocol identification
- Network troubleshooting
- Cybersecurity investigations

🔗 https://www.wireshark.org/docs/

🔗 https://www.wireshark.org/download.html

---

## Nmap

Network discovery and security auditing tool.

Useful for:
- Host discovery
- Port scanning
- Service detection
- Network enumeration
- Security testing

📖 Official Nmap Book:

🔗 https://nmap.org/book/
