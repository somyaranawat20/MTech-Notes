☕ Java Notes & Resources

This section provides well-structured Java programming notes and recommended learning resources for M.Tech students, covering Java concepts from basic to advanced level. The notes include Java fundamentals, OOP concepts, exception handling, collections, file handling, multithreading, JDBC, and practical programming. To support deeper learning, this repository also recommends resources such as Java 2: The Complete Reference – Herbert Schildt, Head First Java – Kathy Sierra & Bert Bates, NPTEL Programming in Java – Prof. Debasis Samanta (IIT Kharagpur), SWAYAM Web Technology – Prof. Dr. Ashutosh Kumar Bhatt, and YouTube channels such as CodeWithHarry, Apna College, and Telusko. These resources are intended to support conceptual understanding, practical coding, university examinations, revision, and interview preparation.
